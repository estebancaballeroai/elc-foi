# Bible Aventure — Les Sentiers d’Éden (v0.2 Premium)

Jeu chrétien éducatif gratuit pour les 7–11 ans : cinq chapitres autour de Genèse 2–3, deux difficultés, missions, livres illustrés, énigmes, récompenses et sauvegarde locale.

**Jouer en ligne :** https://estebancaballeroai.github.io/elc-foi/bible-aventure/

## Utilisation

- Ouvrir `index.html` dans le navigateur (aucune dépendance, aucune connexion nécessaire pour jouer après ouverture).
- Sur une vieille tablette Android, privilégier l'adresse GitHub Pages si le navigateur interdit l'ouverture de fichiers HTML locaux.
- Le jeu se commande au toucher, avec les flèches ou au clavier.
- Régler la voix depuis l'icône des paramètres. Seules les voix françaises disponibles sur l'appareil sont proposées.
- La sauvegarde reste sur cet appareil, dans le navigateur, via `localStorage`.

## Contenu

- 5 labyrinthes de taille croissante, deux variantes de difficulté.
- 15 livres de découverte, 13 énigmes, 20 souvenirs naturels.
- Étoiles, 6 insignes, fresque narrative en cinq scènes et quiz de fin d'aventure.
- Choix d'Adam, puis possibilité de choisir Ève à partir du chapitre 2.

## Précautions pédagogiques

Adaptation pédagogique dans une sensibilité protestante évangélique, fondée sur Genèse 2–3. Les lieux illustrés, collectibles, mécanismes et accessoires sont imaginaires : ils ne constituent ni une reconstitution historique ni une citation littérale du texte biblique. Aucun objet n'est une représentation de Dieu. La réponse à une question ne bloque jamais la suite.
